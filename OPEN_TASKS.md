# Open integration and acceptance tasks

## Historical verification (30 September 2026)

These are rehearsal observations, not a claim that services are running now. The local Redis Enterprise container and its dedicated data volume were removed on 1 October 2026. Hosted demo resources are being retired separately; provision fresh services and rerun checks before another event.

- The local Redis Enterprise container ran; Redis Search and JSON worked. The mission board wrote directly to Redis and was labelled **simulated RDI**. No PostgreSQL or CDC was used.
- The physical Reachy Mini Lite daemon detected all motors, its USB camera returned a 1080p frame, and the presenter ran with RT-DETR R18 plus ByteTrack enabled. The local RSI-Jev service routed the story questions.
- The saved Hugging Face answer and speech recognition endpoints returned HTTP 200. The answer endpoint is OpenAI-compatible chat with model `Qwen/Qwen3-1.7B`; its non-thinking response was verified. OpenAI Speech API returned 16-bit WAV, and the configured Hugging Face recognizer transcribed it. A five-second Reachy microphone recording was sent to that recognizer with the user's explicit approval and returned text.
- The physical Reachy speaker accepted readback and story audio during rehearsal. The current robot I/O implementation selects the MacBook's built-in speakers for output. Confirm volume and clarity on the actual presentation setup.
- Reachy's speech-driven head wobble was observed during rehearsal; live pose samples ranged 7.12° in roll, 8.15° in pitch, and 17.8° in yaw. The user confirmed visible movement. The presenter exposes motor-loop and wobble status for diagnosis.
- A synthetic two-person live story passed memory recall, cache miss/hit, cited Search, direct CLOSED station update, and a finale containing the second person's fact, priority rule, and CLOSED status. The finale needed a confirmed-data guardrail because the hosted model omitted the fact. The test event was ended; 12 event keys were deleted and only its expiring closure marker remained. The focused Redis integration tests passed (8/8).
- Agent Memory and LangCache service health returned 200 during rehearsal; Context Retriever accepted its agent key with `X-API-Key`, listed seven MCP tools, and its generated mission-rule search worked. Its MCP URL and key suffice for connection; no separate surface ID is required. **The app still labels these three as local equivalents because their native adapters and event deletion are not enabled.**
